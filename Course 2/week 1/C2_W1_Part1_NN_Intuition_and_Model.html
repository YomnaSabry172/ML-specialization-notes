1. Origins — Neurons and the Brain

Neural networks were originally invented to try to mimic how the biological brain learns and thinks. That motivation is largely historical now — modern deep learning barely resembles real neuroscience — but the vocabulary stuck: neuron, activation, layer.

Biological neuron → artificial neuron

BiologicalArtificial
Dendrites (input wires)Input features (x₁, x₂, ...)
Cell body (computation)Weighted sum + activation function
Axon (output wire)Output value (activation, "a")
Electrical impulse strengthNumeric output value
Why this matters: This is a deliberate simplification, not a real brain model. Andrew Ng is explicit about this: "we have almost no idea how the human brain works," and today's researchers build neural nets using engineering principles, not biology. Don't over-invest in the biological metaphor — it's a naming convention, not a design constraint.

Brief history (why it matters practically)

  • 1950s: Neural networks first proposed → fell out of favor.
  • 1980s–early 1990s: Resurged, worked well for handwritten digit recognition (postal codes, check reading) → fell out of favor again.
  • ~2005 onward: Resurged again, rebranded as "deep learning."
  • 2010s: Speech recognition → Computer vision (ImageNet moment, 2012) → NLP → now almost every domain (medical imaging, climate, recommendations, etc.)

2. Why Neural Networks Took Off Now

Two things changed: data and compute.

The data-scaling story

Traditional algorithms like linear/logistic regression plateau in performance even as you feed them more data — they can't take advantage of "big data." Neural networks, especially large

Analogy: Think of traditional ML models as a small water pipe — no matter how much water (data) you pump in, only so much can flow through. Large neural networks are like a much wider pipe: more data straightforwardly translates into more flow (better performance), especially for large models.
Model sizeBehavior as data grows
Logistic/Linear RegressionPerformance plateaus early
Small Neural NetworkPlateaus later, but still plateaus
Medium Neural NetworkHigher plateau
Large Neural NetworkKeeps improving with more data (for many applications)
Why this matters: This is the practical reason "should I collect more data or build a bigger model?" is a real, non-trivial decision you'll face — and it's exactly what Course 2's Week 3 (practical advice) will teach you to reason about systematically.

The second driver: faster hardware, especially GPUs (originally built for graphics, repurposed for the matrix multiplications neural nets need).

3. Demand Prediction — the Core Example

This is the running example used to build intuition for what a neural network actually is.

Step 1: A single neuron ≈ logistic regression

Predicting whether a T-shirt is a top seller from its price alone, using logistic regression, gives:

a = g(w·x + b) = 1 / (1 + e−(wx+b))

Here the output is renamed from f(x) to a — short for activation, borrowed from neuroscience (how strongly a neuron "fires"). This single logistic regression unit is the simplest possible artificial neuron: it's a tiny computer that takes in a number (or numbers) and outputs one number.

Step 2: Multiple neurons → a layer

Now use 4 input features: price, shipping cost, marketing, material quality. Intuitively, top-seller status depends on three underlying factors:

  • Affordability — driven mainly by price + shipping cost
  • Awareness — driven mainly by marketing spend
  • Perceived quality — driven mainly by price + material

Each of these is estimated by its own little logistic regression neuron. These three neurons, grouped side by side, form a layer. Their three outputs (activations) feed into one final neuron — the output layer — which outputs the probability of being a top seller.

Input layer (4 numbers) → hidden layer (3 neurons → 3 activation numbers) → output layer (1 neuron → 1 number)
Why it matters: This is the whole idea of a neural network in miniature: layers of neurons, each taking a vector of numbers in and producing a (usually smaller) vector of numbers out, until you reach one final prediction.

Step 3: Every neuron sees every input (in practice)

Conceptually we assigned specific inputs to each neuron (price+shipping → affordability, etc.). In actual implementations, this hand-assignment is not done manually. Every neuron in a layer is connected to every feature from the previous layer, and the neuron learns via its weights which inputs matter and which to effectively ignore (by driving their weights toward zero).

This is why the input layer is drawn with an input vector x feeding fully into the hidden layer with arrows from every input to every neuron — not selectively wired.

Step 4: The hidden layer

The middle layer is called a hidden layer because during training, you only observe x (inputs) and y (true top-seller label) — you never directly observe the "correct" affordability/awareness/quality values. Those are computed internally and are hidden from the training data.

Analogy: It's like a factory where you know the raw materials going in and the finished product coming out, but the exact intermediate assembly steps happening inside are not written down anywhere — they're inferred, not observed.

Step 5: A powerful reframe — automatic feature engineering

Cover the left half of the diagram and look only at the final neuron: it's just logistic regression using affordability, awareness, perceived quality as its 3 input features instead of the original 4 raw features. In Course 1, you built features like this by hand (e.g., multiplying lot frontage × depth to get lot area). A neural network builds its own better features automatically, layer by layer, directly from data — without you specifying them.

Why this matters (this is the big one): This is precisely what makes neural networks so powerful — they remove the need for manual feature engineering, which was one of the most labor-intensive and skill-dependent parts of classical ML.

Stacking more layers

Nothing stops you from chaining several hidden layers: input → hidden layer 1 → hidden layer 2 → hidden layer 3 → output layer. A network like this (multiple layers stacked) is sometimes called a multilayer perceptron in older literature.

How many hidden layers, and how many neurons per layer, is called the network's architecture — a design choice with real performance consequences (covered later in the course).

4. Computer Vision Examples (Faces & Cars)

The same layered idea generalizes beyond tabular data (T-shirt features) to raw pixels.

Face recognition

A 1000×1000 pixel image is really a 1000×1000 grid of brightness values (0–255). Unroll that grid into a vector and you get 1 million numbers as your input feature vector x. A multi-layer network is trained to map this vector to a probability over identities.

What each hidden layer "looks for," visualized layer by layer

When you visualize what individual neurons detect, a clear hierarchy emerges:

  • Layer 1: tiny, short edges/lines at various orientations (small receptive window)
  • Layer 2: parts of faces — an eye, corner of a nose, edge of an ear (bigger window; combinations of Layer-1 edges)
  • Layer 3: coarse, almost-complete face shapes (even bigger window)
  • Output layer: combines these into an identity probability

Car classification — same network, different data

The identical architecture, trained on car images instead, learns car-relevant features automatically

Trained on car images instead, the exact same architecture learns edges → car parts → whole car shapes, entirely on its own. Nobody told it to look for wheel arches or bumpers.

Why this matters: No one manually programmed "look for eyes" or "look for wheels." The network discovered a hierarchy of increasingly abstract, task-relevant features purely from data — the same automatic feature-learning idea from the demand prediction example, just far more dramatic at scale.

5. The Neural Network Layer — the Fundamental Building Block

Zooming into one layer's computation (using the demand prediction hidden layer as the running example):

Each neuron = its own tiny logistic regression

Each neuron in layer 1 has its own parameters w and b:

a₁ = g(w₁ · x + b₁)   → e.g. 0.3 (affordability)
a₂ = g(w₂ · x + b₂)   → e.g. 0.7 (awareness)
a₃ = g(w₃ · x + b₃)   → e.g. 0.2 (perceived quality)

where g is the sigmoid function. These three numbers together form the output vector of the layer: a = [0.3, 0.7, 0.2], which becomes the input to the next layer.

The output layer

Layer 2 has just one neuron. It takes the 3-number vector from layer 1 as its input:

a₁⁽²⁾ = g(w₁⁽²⁾ · a⁽¹⁾ + b₁⁽²⁾) → e.g. 0.84

Optional final step: thresholding

If you want a hard yes/no prediction instead of a probability:

if a⁽²⁾₁ ≥ 0.5 → ŷ = 1    |    if a⁽²⁾₁ < 0.5 → ŷ = 0

Same thresholding logic as logistic regression in Course 1.

Why it matters: Every layer, no matter how deep the network, does the same basic operation: take a vector in, apply a set of independent logistic-regression-like units, output a new vector. Understanding one layer means you understand the repeating unit of the entire network.

6. Notation for Deeper Networks

Superscript square brackets denote which layer a quantity belongs to. Subscripts denote which neuron/unit within that layer.

aj[l]  =  g( wj[l] · a[l−1]  +  bj[l] )
SymbolMeaning
lLayer index (1, 2, 3, ...)
jNeuron/unit index within layer l
a[l]Vector of activations output by layer l
a[l−1]Input to layer l = output of the previous layer
wj[l], bj[l]Parameters of the j-th neuron in layer l
gThe activation function (sigmoid so far — more options coming in Week 2)
Convention: the input layer is called layer 0, so a[0] = x. This makes the formula above valid even for layer 1: a[1] = g(w[1]·a[0] + b[1]) = g(w[1]·x + b[1]).
Layer counting convention: When people say "a 4-layer neural network," they count all hidden layers + the output layer, but not the input layer (layer 0 doesn't count).
Why this matters: This notation looks cluttered at first but it's what lets you write one general formula that works for a network of any depth — 2 layers or 200. Once it clicks, every diagram of "boxes and arrows" becomes just repeated applications of this one equation.

7. Forward Propagation (Inference)

Forward propagation is the algorithm for computing a neural network's prediction: propagate activations layer by layer, left to right, from input to output.

Worked example: handwritten digit recognition (0 vs. 1)

An 8×8 pixel image (64 pixel intensities) is fed into a network with:

  • Layer 1: 25 units → outputs a⁽¹⁾ (25 numbers)
  • Layer 2: 15 units → outputs a⁽²⁾ (15 numbers)
  • Layer 3 (output): 1 unit → outputs a⁽³⁾ (1 number, a probability)
x → a⁽¹⁾ → a⁽²⁾ → a⁽³⁾ = f(x), then threshold a⁽³⁾ at 0.5 for ŷ
a⁽¹⁾ = g(W⁽¹⁾·x + b⁽¹⁾)   (25 numbers)
a⁽²⁾ = g(W⁽²⁾·a⁽¹⁾ + b⁽²⁾)   (15 numbers)
a⁽³⁾ = g(W⁽³⁾·a⁽²⁾ + b⁽³⁾)   (1 number) = f(x)

Notice the pattern: 64 → 25 → 15 → 1. The number of units decreases as you approach the output. This "funnel" shape (more units early, fewer near output) is a common — though not mandatory — architectural choice.

Why it's called "forward" propagation: Computation flows strictly left-to-right, from input toward output. This is in contrast to backward propagation (backpropagation), which you'll meet next week — that's the algorithm used for training (learning the weights), and it flows in the opposite direction.
Forward propagation is also exactly what lets you take someone else's already-trained network (with parameters posted online) and use it to make predictions on your own new data — no training required, just inference.

8. Lab 01 — Neurons and Layers (TensorFlow / Keras)

This lab is the bridge from Course 1's math to actual code, using Keras (integrated into TensorFlow 2.0, originally an independent framework by François Chollet).

Part A — Neuron without activation ≈ Linear Regression

A single Dense layer with activation='linear' and 1 unit computes exactly:

fw,b(x) = w·x + b
linear_layer = tf.keras.layers.Dense(units=1, activation='linear')

# Weights don't exist until the layer sees data (they get "built" on first call)
a1 = linear_layer(X_train[0].reshape(1,1))   # triggers weight creation

w, b = linear_layer.get_weights()             # inspect them
linear_layer.set_weights([np.array([[200]]), np.array([100])])  # set manually
Key implementation detail: Keras layers must receive 2-D input — even a single scalar feature must be reshaped, e.g. X_train[0].reshape(1,1). This trips people up constantly: TensorFlow always expects a batch dimension.

The lab confirms that linear_layer(x) and manually computing np.dot(w, x) + b give identical results — proving the Dense layer really is just doing w·x + b under the hood.

Part B — Neuron with Sigmoid activation ≈ Logistic Regression

fw,b(x) = g(w·x + b),   g = sigmoid
model = Sequential([
    tf.keras.layers.Dense(1, input_dim=1, activation='sigmoid', name='L1')
])

model.summary()   # shows layer, output shape, and # of parameters (2: w and b)

logistic_layer = model.get_layer('L1')
w, b = logistic_layer.get_weights()

logistic_layer.set_weights([np.array([[2]]), np.array([-4.5])])

Again, model.predict(x) is checked against a manual NumPy sigmoid computation — same result, confirming the Dense+sigmoid layer is literally logistic regression wrapped in Keras's layer API.

Core takeaways from Lab 01

Why this lab matters: It proves — very concretely, with matching numbers — that a "neuron" in a neural network isn't a new mysterious object. A neuron with no activation is linear regression; a neuron with sigmoid activation is logistic regression. Neural networks are built by composing many of these familiar units together in layers. Everything from Course 1 is still inside Course 2 — it's just been made modular and stackable.

9. Quick-Reference Summary

TermMeaning
Neuron / unitA single logistic-regression-like computation: g(w·x + b)
Activation (a)The output number(s) of a neuron/layer
LayerA group of neurons that take the same input vector and each output one number
Input layer (layer 0)The raw feature vector x, a⁽⁰⁾ = x
Hidden layerAny layer between input and output; its "correct" values aren't in the training data
Output layerFinal layer; produces the network's prediction
ArchitectureNumber of layers + number of neurons per layer
Forward propagationComputing predictions by passing activations left→right through the layers
Multilayer perceptronOlder term for a neural network with multiple stacked layers
Big-picture analogy: A neural network is an assembly line. Raw materials (x) enter at station 0. Each subsequent station (layer) takes what the previous station produced, does its own transformation, and passes a new, more refined product downstream — until the final station outputs the finished item (the prediction). No single station needs to understand the whole product; it just needs to do its local transformation well, and the network learns what each station should do from data.
