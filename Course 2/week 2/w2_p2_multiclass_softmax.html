1. Multiclass classification

Still a classification problem — y is one of a small number of discrete categories — but now y can take on more than two values (e.g. which digit, 0–9; which of several diseases; which defect type). Instead of estimating one probability P(y=1|x), the algorithm now estimates P(y=1|x), P(y=2|x), ..., P(y=N|x).

One dividing line vs. a boundary splitting the space into 4 regions.

2. Softmax regression

Softmax regression generalizes logistic regression to N classes. Trick to see the link: logistic regression can be re-framed as computing two numbers that sum to 1 — a1=P(y=1|x) and a2=1−a1=P(y=0|x). Softmax extends this to N numbers:

zj = wj·x + bj  (j = 1...N)     aj = ezj / Σk=1N ezk = P(y=j|x)
Why this matters: the softmax formula forces a1+...+aN=1 automatically — every numerator also sits inside every denominator. With N=2 it reduces exactly to logistic regression.

3. Softmax cost function

loss(a1,...,aN, y) = −log(aj)  where j is the true class

Only the aj matching the true label counts — as it → 1, loss → 0; as it → 0, loss → ∞. Pushes the model to concentrate probability on the correct class.

J(w,b) = −(1/m) Σi Σj 1{y(i)==j} · log(aj(i))

4. Softmax in a neural network

Swap the output layer for a softmax layer with one unit per class — 10 units for digit recognition 0–9. Hidden layers stay ReLU as usual.

model = Sequential([
    Dense(units=25, activation='relu'),
    Dense(units=15, activation='relu'),
    Dense(units=10, activation='softmax')
])
model.compile(loss=SparseCategoricalCrossentropy())
model.fit(X, y, epochs=100)
Sparse categorical: "categorical" = y falls into categories; "sparse" = each example has exactly one true category (never simultaneously a 2 and a 7).
This works but isn't the recommended version — see the numerically accurate form below.
Softmax is unusual: sigmoid/ReLU compute each aj from its own zj alone. Softmax computes every aj from all the z's at once — change any one z and every output shifts, since they all share the same denominator.

5. Numerical stability & the preferred implementation

Computing 2/10000 directly is more numerically accurate on a computer than computing it as (1+1/10000) − (1−1/10000), even though they're mathematically equal — intermediate floating-point values introduce round-off error. The fix: avoid unnecessary intermediate steps.

Applied to softmax: instead of computing a1...a10 explicitly and then plugging them into the loss, let the output layer emit raw z's (linear activation) and fold softmax + log-loss into one step via from_logits=True. Same idea applies to logistic regression's sigmoid + binary cross-entropy.

model = Sequential([
    Dense(units=25, activation='relu'),
    Dense(units=15, activation='relu'),
    Dense(units=10, activation='linear')     # <-- linear, not softmax
])
model.compile(loss=SparseCategoricalCrossentropy(from_logits=True))
model.fit(X, y, epochs=100)

logits = model(X)              # these are z1...z10, NOT probabilities
f_x = tf.nn.softmax(logits)    # convert to probabilities when needed
· Logistic regression, same pattern:
Dense(units=1, activation='linear')
compile(loss=BinaryCrossentropy(from_logits=True))
logit = model(X); f_x = tf.nn.sigmoid(logit)
Gotcha: with this setup the model's raw output is logits, not probabilities. Pass through tf.nn.softmax() (or tf.nn.sigmoid()) if you need actual probabilities. For just picking the predicted class, argmax on raw logits is enough.

6. Multi-label classification

Not the same as multiclass. Multiclass = one label per example, chosen from N mutually exclusive categories. Multi-label = several independent yes/no labels on the same example (e.g. does this image contain a car? a bus? a pedestrian? — any combination can be true).
y = [car?, bus?, pedestrian?]  e.g. y = [1, 0, 1]
Why sigmoid, not softmax: labels aren't mutually exclusive here — car, bus, and pedestrian can all be present at once. Softmax forces outputs to compete and sum to 1; each label instead gets its own independent sigmoid, same as running 3 binary classifiers off shared hidden layers.
